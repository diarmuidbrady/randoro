Randoro is a boxing interval timer that fires random audio cues so you have to react to what to the unpredictable. 

Used by Diarmuid to train solo and coach beginner boxing classes.

**Current state (as of May 2026):**
- TestFlight build 1.0.0 (build 3) is live with: home screen animation, tooltip redesign, Combo Count label, sound picker removed, tagline "react to the unpredictable"
- Apple Developer account enrolled, TestFlight set up
- Works with Bluetooth speaker in foreground, background, and lock screen
- App experiences occasional audio glitches — root cause not isolated

**Queued work:**
- Logo/app icon: QRS waveform design — dot in animation to follow exact QRS path
- Future animation features: jet trail on dot, dot fades red during QRS portion
- App icon design in progress
