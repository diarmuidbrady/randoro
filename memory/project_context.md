Randoro is a boxing interval timer that fires random audio cues so you have to react to what you can't predict. 

Used by Diarmuid to train solo and coach beginner boxing classes.

**Current state (as of May 2026):**
- TestFlight build 1.0.0 (build 2) is live; dev branch is ahead with audio fix, rounds picker, and info tooltips
- Apple Developer account enrolled, TestFlight set up
- Works with Bluetooth speaker in foreground, background, and lock screen
- App experiences occasional audio glitches — root cause not isolated
